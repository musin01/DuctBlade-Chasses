# Аэродинамический паспорт и таблицы наладки ПНР

Расчеты требуемого расхода воздуха выполнены по базовой формуле теплового баланса:

```text
L = (3.6 × Q) / (c × ρ × ΔT)
```

где:
* **L** — требуемый расход воздуха, м³/ч;
* **Q** — суммарная тепловая мощность (потребление сборки от розетки), Вт;
* **c × ρ ≈ 1.205 кДж/(м³·К)** — объемная теплоемкость воздуха при стандартных условиях;
* **ΔT** — допустимый нагрев воздуха внутри корпуса, °C.

### Рабочие режимы пусконаладки (ПНР)
1. **Режим «Комфорт / Тишина» (ΔT = 12 °C):** Основной расчетный режим (например, вход +18 °C от канального кондиционера, выход +30 °C). Обеспечивает минимальную скорость потока и полное отсутствие аэродинамического шума.
2. **Режим «Форсаж / Жара» (ΔT = 10 °C):** Режим повышенного воздухообмена с запасом (вход +20 °C, выход +30 °C).

## 3. Инструкция для наладчика ПНР

1. **Балансировка ветки:** Настройка дроссель-клапанов (или VAV-заслонок) выполняется по **номинальной (средней) тепловой нагрузке** сборки под рабочими задачами, а не по кратковременному пику (например, для игрового ПК с пиком 1000 Вт средняя полка составляет ~650–700 Вт → настраиваем суммарный расход на `180–210 м³/ч`, т.е. по `90–105 м³/ч` на каждый фланец).
2. **Асимметрия потоков в модели Pro:** При наладке двух приточных фланцев `204 × 60 мм` рекомендуется распределять расход в пропорции **40% на зону CPU / VRM** и **60% на зону GPU** (регулируется дросселями на ответвлениях).
3. **Запас по статическому давлению:** Минимальный располагаемый перепад давления на входе в корпус должен составлять не менее **25–35 Па** для преодоления аэродинамического сопротивления радиаторов и надежного прижатия лепестков аварийного байпаса. При монтаже в вытяжной канал перед рекуператором дополнительно закладывается **+80–100 Па** на загрязнение входного фильтра класса G4.
